# Pizzaria Ki Delicia

Landing page estática desenvolvida para uma pizzaria utilizando HTML5 e CSS java script.

## Objetivo

Desenvolver uma landing page responsiva para a Pizzaria Ki Delicia, demonstrando conhecimentos de HTML5, CSS3 e java script, navegação por âncoras, formulários, responsividade e organização de arquivos,preecher formulário e aparecer mensagem de erro se os campos não forem preenchidos corretamente.

## Tecnologias utilizadas

- HTML5
- CSS3
- java script
- Font Awesome
- Visual Studio Code
